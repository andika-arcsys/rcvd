Taruh file model Real-ESRGAN ncnn (pasangan .param + .bin) untuk halaman /resolv.

Mengikuti sistem RESOLV (https://github.com/angslhn/RESOLV), lokasi yang
disarankan adalah langsung di folder "models/" (bukan subfolder ini). Folder
"models/realesrgan/" ini juga tetap diterima sebagai lokasi alternatif.

Model yang dikenali oleh dropdown di /resolv (semua native x4):

  realesrgan-x4plus.param        + realesrgan-x4plus.bin          (General)
  realesrgan-x4plus-anime.param  + realesrgan-x4plus-anime.bin    (Anime)
  realesr-animevideov3-x4.param  + realesr-animevideov3-x4.bin    (Anime Video)

File ini biasanya sudah termasuk di dalam arsip rilis Real-ESRGAN-ncnn-vulkan,
di dalam subfolder "models":
  https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases

Nama file harus PERSIS seperti di atas. Jika model belum ada, downscale
(0.25x-0.99x) dan noop (1.0x) tetap berfungsi; hanya upscale (>1.0x) yang butuh
binary + model ini.
