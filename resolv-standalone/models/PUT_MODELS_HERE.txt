Taruh file model Real-ESRGAN ncnn (pasangan .param + .bin) di folder ini.

Model yang dikenali oleh aplikasi (semua native x4):

  realesrgan-x4plus.param        + realesrgan-x4plus.bin          (General)
  realesrgan-x4plus-anime.param  + realesrgan-x4plus-anime.bin    (Anime)
  realesr-animevideov3-x4.param  + realesr-animevideov3-x4.bin    (Anime Video)

File ini biasanya sudah termasuk di dalam arsip rilis Real-ESRGAN-ncnn-vulkan
(di dalam subfolder "models"):
  https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases

Nama file harus PERSIS seperti di atas agar cocok dengan pilihan model di UI.
Downscale (<1x) dan noop (1x) tetap berfungsi tanpa model ini; hanya upscale
(>1x) yang membutuhkannya.
